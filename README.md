# Videx

Современное Android-приложение для загрузки видео, аудио и фото с популярных сервисов (YouTube, TikTok, Instagram, VK и сотен других). Построено на Jetpack Compose и локальном движке `yt-dlp` (Python 3.13).

---

## Возможности

- **Загрузка медиаконтента**: Скачивание видео в высоком качестве (до 4K/60FPS), извлечение аудиодорожек (MP3/M4A), а также скачивание фото и слайдшоу (Instagram, TikTok).
- **Локальный движок yt-dlp**: Запуск CPython 3.13 прямо на устройстве через Chaquopy без сторонних серверов.
- **Автоматическое обновление парсеров**: Поддержка автоматического и ручного обновления yt-dlp прямо из приложения (OTA updates).
- **Встроенный видеоплеер**: Плеер на базе ExoPlayer с поддержкой жестов (громкость, яркость, перемотка), выбора скорости, соотношения сторон и режима Картинка-в-картинке (PiP).
- **Фоновые загрузки**: Скачивание файлов через WorkManager с уведомлениями о прогрессе и управлением очередью.
- **История и галерея**: Сохранение истории загрузок в Room DB и интеграция с системным MediaStore.
- **Material 3 UI**: Современный интерфейс на Jetpack Compose с поддержкой темной и светлой темы.

## Технологии

| Компонент | Технологический стек |
| :--- | :--- |
| **Язык** | Kotlin |
| **UI** | Jetpack Compose, Material 3 |
| **Архитектура** | MVVM, ViewModels, StateFlow |
| **Плеер** | Media3 ExoPlayer |
| **База данных** | Room DB |
| **Фоновые задачи** | WorkManager |
| **Python-движок** | Chaquopy (CPython 3.13), `yt-dlp`, `requests` |
| **Сеть и изображения** | OkHttp 4, Coil |

## Сборка и запуск

### Требования
- Android Studio Ladybug (2024.2.1) или новее
- JDK 17
- Android SDK 36 (Android 16 Ready, minSdk 26)

### Сборка Release APK
Для создания готового к установке APK-файла выполните команду в терминале:

```bash
./gradlew assembleRelease
```

Готовый файл APK будет находиться по пути:
`app/build/outputs/apk/release/app-release.apk`
