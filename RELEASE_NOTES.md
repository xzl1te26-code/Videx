Релиз версии v1.1.4.

Что нового:

• **Защита данных при удалении приложения (Fragile User Data Protection):**
  — В манифест приложения интегрирован системный атрибут `hasFragileUserData="true"`.
  — Теперь на Android 10+ при зажатии иконки и удалении Videx операционная система выводит системный диалог: *«Сохранить данные приложения?»*.
  — При получении согласия пользователя все скачивания, настройки и база данных Истории остаются в памяти устройства и автоматически восстанавливаются при повторной установке приложения.
• **Единый универсальный ключ подписи (Unified Signing Key):**
  — В репозиторий заложен единый проектный ключ подписи `release.keystore`, который используется как в локальной сборке из Android Studio, так и в облачном авто-билде на серверах GitHub Actions.
  — Полностью устранена проблема с ошибкой *«Приложение не установлено»* при бесшовном обновлении с предыдущих версий.

Исправления (Bug fixes):

• **Надежная генерация релиза в CI/CD:** в рабочий процесс GitHub Actions добавлено явное разрешение `permissions: contents: write` для корректной авто-публикации APK-файлов на странице релизов.
• **Стабильная сборка Python в облаке:** конфигурация Chaquopy и GitHub Actions синхронизированы на Python 3.13 для 100% успеваемости авто-сборки.
